This site is called rommy.blog. It is a personal blog.

The pages are plain HTML, generated by a Node.js build script. No framework, no bundler, no dependencies at runtime. Content lives in a Cloudflare D1 database — posts, drafts, reading, sharing, and thinking. Photos upload to R2 and cross-post via Micropub and Bluesky. The build script reads from D1 at deploy time and writes out static HTML. The source code lives on GitHub. The site is built on every push and hosted on Cloudflare Pages (it previously ran on GitHub Pages). A scheduled GitHub Action triggers an hourly rebuild via a Cloudflare deploy hook.

The design is intentionally minimal — a warm off-white background, a single typeface (Inter), and no images except where the writing calls for one. Dark mode is available and remembered between visits.

Writing is composed in a custom admin interface and published through a Cloudflare Worker that writes to D1 and triggers a site rebuild. Drafts are stored in D1; every edit keeps a version history. Thinking posts are mirrored simultaneously to Micro.blog and Bluesky.

The Thinking archive pulls live from Micro.blog's JSON feed at build time. Each post gets its own page here.

Reading is a running log of books, linked to Bookshop.org. Sharing is a linklog. The Changelog is generated from Git commit history.

Visitor analytics are handled by Google Analytics 4. There are no comments, no tracking pixels, and no JavaScript frameworks.

The contact form is handled by Formspree.

Built and maintained with the help of Cursor.
