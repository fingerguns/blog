This site is called rommy.blog. It is a personal blog.

The pages are plain HTML, generated by a Node.js build script into dist/ at deploy time. No framework, no bundler, and no npm dependencies at runtime. Generated pages are not committed to Git — only source, styles, and hand-authored pages live in the repo. Content lives in a Cloudflare D1 database — Writing posts, drafts, Reading, Sharing, and Thinking notes (text plus optional photos). The build script reads D1 on each deploy and writes static HTML to Cloudflare Pages. Source code is on GitHub (source only — not hosting). The site is served exclusively on Cloudflare Pages. Saving content from the admin triggers a Pages rebuild via deploy hook; pushes to main rebuild as well.

Editing happens in a password-protected admin UI, gated by Cloudflare Access before the blog password. A Cloudflare Worker handles the API: it writes to D1, uploads photos to R2 (public bucket) for both Thinking and Writing, cross-posts Thinking to Micro.blog via Micropub, and cross-posts to Bluesky when configured (Bluesky truncates at 300 characters; the admin shows a soft 300-character guide while typing). Thinking accepts optional text and an optional photo; the admin archive lists past notes in full and links to delete them on the site (and from Micro.blog and Bluesky when syndication was saved). Writing uses Quill: insert images from the toolbar, keep typing in the same paragraph so text wraps, then click a photo to show controls below the toolbar — Left, Right, Center, Full, or Delete. On save, the Worker and build script merge image-only paragraphs with the following paragraph so floats render correctly in static HTML. Drafts and explicit Save draft; published posts keep a version history in D1.

Photos are served from R2 at full size on rommy.blog and Micro.blog (up to 5 MB). Bluesky receives a compressed JPEG when the original exceeds 2 MB. Portrait-oriented photos default to half width on the site; click once to enlarge, again to shrink back (Thinking and Writing).

The homepage Thinking section, Thinking archive, and per-post pages all come from D1 (thinking_posts), including R2-hosted images. Permalink slugs use US Eastern time. Bare URLs in Thinking notes become plain links on rommy.blog; #hashtags link out to the matching hashtag page on Bluesky. There are no embedded preview cards on the site itself — Bluesky and Micro.blog unfurl links in their own clients when you cross-post, and Bluesky turns hashtags into clickable tags on the syndicated post.

When someone shares a rommy.blog URL elsewhere (iMessage, Bluesky, and so on), the build script emits Open Graph and Twitter meta tags: Writing posts use the summary and the first in-post image when available; Thinking permalinks use a text snippet and the first image in the note, with a favicon fallback.

Writing permalinks have comments via self-hosted Remark42 on Fly.io at comments.rommy.blog (DNS through Cloudflare). The build embeds the widget on each Writing post; anonymous sign-in is enabled. Custom CSS on the Remark42 server matches this site’s Inter, colors, and link styling, and the footer theme toggle keeps the comment iframe in sync with light/dark mode. Thinking has no comments.

The design is intentionally minimal — warm off-white, a single typeface (Inter), and photos where they belong (Thinking and Writing). Dark mode is toggled in the footer and remembered between visits. Aside from theme toggle, archive “load more,” portrait photo expand/collapse, and the Remark42 embed on Writing posts, there is no client-side framework.

Reading is a running log of books, linked to Bookshop.org. Sharing is a linklog. The Changelog is generated from Git commit history. Dates on the site display in US Eastern time.

Visitor analytics use Google Analytics 4. The contact form is handled by Formspree.
